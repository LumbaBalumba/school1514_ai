# Занятие 02. Графики и таблицы в Python

Материалы для первого знакомства с Matplotlib, pandas и Seaborn. Предполагаются
только основы Python: переменные, списки, словари и вызов функций.

Примеры относятся к разным задачам: температуре и ветру, математической функции,
велосипедным поездкам, продажам напитков и товарам магазина. Школьных оценок
и набора данных об учениках здесь нет. Все данные вымышлены.

## Порядок объяснения

Сначала рисуем по обычным спискам через `plt.plot`, `plt.scatter`, `plt.bar` и
`plt.hist`. По ходу разбираются координаты точки, подписи осей, единицы, легенда
и смысл высоты столбца или интервала. `fig, ax` в этих примерах не нужны.

Затем появляется pandas: объясняем, зачем нужна таблица, создаём DataFrame
из четырёх товаров и читаем его по строкам и столбцам. На нём можно вручную проверить
среднюю цену, маску, отбор, сортировку, выручку и сумму по категориям. До применения
фильтра маска показывается отдельно, а `groupby` объясняется как разделение строк
на группы с последующим вычислением.

После маленькой таблицы читаем CSV с поездками. Разбираемся с конкретными пропусками
и одним техническим повтором, затем строим график по двум столбцам. Seaborn сначала
рисует те же точки, после чего цвет связывается с типом велосипеда через `hue`.

После Matplotlib и Seaborn идёт отдельная часть о встроенной визуализации pandas:
`Series.plot()` для столбцов и гистограммы, `DataFrame.plot()` для точек и двух линий.
В конце сохраняем таблицу и рисунок. Две области через `fig, axes` вынесены
в дополнительную часть, для обязательного ДЗ они не требуются.

Материал лучше разбить на несколько встреч, оставляя время повторить пример
и объяснить результат. Не стоит проходить все команды подряд без самостоятельной пробы.

## Данные

`data/weather.csv` содержит 14 дней: `day`, температуры `moscow` и `kazan` в °C,
`wind_ms` — скорость ветра в м/с. Пропусков нет.

`data/rides.csv` содержит `trip_id` — номер поездки, `bike` — тип велосипеда,
`distance_km` — расстояние в километрах, `minutes` — время в минутах.
Всего 61 строка, включая один точный технический повтор. После его удаления —
60 поездок. Неизвестны два расстояния и три длительности; 55 поездок имеют оба
известных числовых признака. Пропуск не заменяется нулём.

Поездки сгенерированы с seed 1514. Связь времени, расстояния и типа велосипеда
заложена в модели: это не реальные измерения и не доказательство преимущества
одного велосипеда. Длительности разных поездок нельзя сравнивать как скорости,
не учитывая расстояние.

Воспроизвести только CSV:

## Пересборка PDF

Для готовых иллюстраций Python запускать не требуется. Нужны pdfLaTeX с Beamer,
русским Babel, T2A, кириллическими шрифтами и `latexmk`:

```bash
cd 02_plots_pandas/slides
latexmk -pdf -interaction=nonstopmode -halt-on-error lesson02.tex
```

Результат — `lesson02.pdf`. Без `latexmk` можно дважды выполнить
`pdflatex -interaction=nonstopmode -halt-on-error lesson02.tex`.
После изменения примеров сначала запустите сборщик материалов, затем эту команду.
